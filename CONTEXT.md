# Glosario

| Término | Definición | Evitar |
|---|---|---|
| Alimento | Fila de `data/alimentos.csv`, valores por 100 g de porción comestible tal como se come | ingrediente, producto |
| Rol | Papel del alimento en el plato (lacteo, cereal, proteina, legumbre, verdura, fruta, grasa…) | categoría |
| Etiqueta | Marca para reglas de frecuencia o vetos (pescado, carne_roja, procesada, aove, alto_potasio…) | tag |
| Comida | Toma del día: D desayuno, MM media mañana, C comida, M merienda, X cena | ingesta, toma |
| Plantilla | Estructura mínima/máxima de grupos de roles en una comida | patrón |
| Perfil | Conjunto de objetivos por defecto para un uso (UAX mediterránea, ERC HD…) | dieta tipo |
| Objetivos | Valores diarios de una persona concreta calculados desde su perfil | metas |
| Menú | Salida del generador: alimentos y gramos por día y comida | plan, dieta |
| BCAA | Leucina + isoleucina + valina (mg/día, mg/kg de peso o de masa magra) | AACR |
| Semilla | Tabla de composición provisional con aminoácidos estimados por patrón; no válida para resultados | — |
| Masa magra | kg de masa libre de grasa (DXA/BIA) para expresar aminoácidos por kg | LBM |
